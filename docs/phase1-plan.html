WEEK 05Library Page + Game Detail

Build the library page with all three views, the game detail page (full route + intercepted panel), and tactile FLIP transitions for status changes.

16Library server actions

getUserLibrary(filters), updateLogStatus, deleteLog. Drizzle queries with explicit user-id filter (RLS as backstop).

17<FilterChips> + <SortDropdown>

Pixel sticky-note style filter chips + sort dropdown. URL state via useSearchParams + router.replace.

18<ShelfFrame> pixel-art shelf wrapper

Wooden plank top + bottom + mascot peeking from corner. Library wall sits inside this frame.

19<LibraryGrid> (poster wall view)

Letterboxd-style small posters. Hover overlay reveals rating + status. Each poster has layoutId for FLIP.

20<LibraryList> (info-dense list view)

60×80 cover thumb + title + hearts + status + dates + hours. Sortable column headers.

21<StatusShelf> (horizontal carousels)

Steam Big Picture vibe — Playing → Up Next → Recently Completed → Wishlist. Reused as dashboard hero.

22/library page with view toggle

RSC fetches initial data, client switcher renders one of grid/list/shelf. URL state for filter, sort, view.

23Tactile FLIP transitions

Status menu on poster hover. Picking a new status → poster physically slides to its new sorted position via Framer Motion FLIP.

24<GameDetail> + <LogCard> + screenshots

Cover hero, metadata strip, log card if logged, RAWG description, screenshots gallery. Used by both panel and full route.

25/games/[slug] full route

RSC fetches game + screenshots + user log. 404 with mascot if slug unknown.

26Intercepting route — slide-over panel

Click poster from inside the app → slide-over panel via Next.js parallel/intercepting routes. Refresh → loads as full route. Mobile fallback to bottom sheet.

WEEK 06Cockpit Dashboard, Profile, Polish

Ship the dashboard, profile page, full edit-log modal, complete the mascot copy, and run the verification gate.

27<MascotGreeting> with context-aware copy

Dashboard hero. Mascot at xl, greeting picks variants based on (hour-of-day, days-since-last-log, currently-playing).

28<StatsStrip> + <ActivityTimeline>

Total + by-status counts + average rating. Recent-activity feed (last 10 events).

29Cockpit dashboard at /home

Authed users at / redirect to /home. Cockpit composed from MascotGreeting + StatusShelf + ActivityTimeline + StatsStrip. Old /dashboard redirects to /home.

30/u/[username] profile page

Header + stats + library grid. Auto-creates profile from email prefix on first sign-in.

31<EditLogModal> — full-form editor

All schema fields: status, rating, started/finished dates, hours, platform, replay flag, privacy toggle, notes textarea. Save + Delete with confirm.

32Author full mascot copy strings

Expand to 3-5 variants per scenario. Tone-review pass — every line passes "ribs your backlog, never insults your taste." 25-35 strings total.

33Verification gate run-through

Manually walk through all 14 acceptance checks from the spec. Cross-browser pass (Chrome / Safari / Firefox + iOS Safari + Chrome Android). Each fix gets its own commit. Final empty commit marks gate passing.
