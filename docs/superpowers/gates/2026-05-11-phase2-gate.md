### Plan deviations noted during execution

- **AI SDK v6.0.177 removed the `ai/rsc` sub-package.** `createStreamableValue` / `readStreamableValue` no longer exist. Replaced with a small shim in `lib/reviews/server-actions.ts` that emits `ReadableStream<string>` with the same `{ value, update, done, error }` surface. Client components consume via the standard web `getReader()` loop wrapped in a `readAccumulatedStream` helper.
- **T11 launchDraft awaits the draft stream client-side** before navigating to the editor. Without this drain, the editor would briefly load with `body=""` since the server's IIFE writes the final body only on stream end.
- **AI SDK v6 renamed `maxTokens` → `maxOutputTokens`** internally. The public `StreamArgs.maxTokens` API is preserved; mapping happens inside each provider's streamText.
- **Cerebras community provider risk** — the @ai-sdk/openai-compatible adapter is used for Cerebras; if the endpoint shape changes we'll need to revisit. No issue at ship time.
